My ToDo v0.6 — iPhoneだけで公開する手順

【準備】
1. このZIPをiPhoneの「ファイル」アプリで展開します。
2. GitHubアカウントを用意し、Safariで github.com にログインします。
3. 新規のPublicリポジトリ（例: my-todo）を作成します。個人のタスクデータはアップロードしないでください。
4. リポジトリの「Add file」→「Upload files」から、展開したフォルダ内のファイルをすべてアップロードし、コミットします。iPhoneではSafariの「デスクトップ用Webサイトを表示」が必要な場合があります。
5. リポジトリの Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
6. 数分待ち、Pages欄に表示された公開URLをSafariで開きます。URLは通常 https://<ユーザー名>.github.io/<リポジトリ名>/ です。
7. Safariの共有メニュー →「ホーム画面に追加」。

【重要】
- GitHub Pages上のアプリのプログラムは公開されますが、タスク内容・勉強記録は通常この端末のブラウザ内に保存され、GitHubにアップロードされません。
- Safariとホーム画面アプリでは保存領域が異なる場合があります。データ移行には「記録」タブのバックアップと復元を利用してください。
- iPhoneのストレージ削除、アプリ削除、サイトデータ削除で記録が失われる可能性があります。定期的にJSONバックアップを作ってください。
- リマインダーはアプリ内表示のみです。画面を閉じた状態のプッシュ通知は未対応です。
- カウントダウンやポモドーロの経過時間は復元できますが、画面を閉じている間の音・通知は保証しません。
- 今回は配布用ファイルの検査まで。実際のiPhone Safari上での動作検証は未実施です。
